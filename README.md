# Prática de JavaScript

Exercícios iniciais sobre eventos, variáveis e operadores.

## Conteúdo

O arquivo [`js.4/script.js`](js.4/script.js) contém testes com o evento `DOMContentLoaded`, alteração de estilo da página, valores em variáveis, operações aritméticas e comparações.

## Como explorar

Abra [`js.4/index.html`](js.4/index.html) no navegador e acompanhe as mensagens no console das ferramentas de desenvolvedor. O carregamento da página também exibe um alerta.

> Projeto de estudos, mantido como registro da minha evolução em JavaScript.
